# Dirección visual de 4PACK

## Referencias aprobadas

- https://mobile-user-panel-de-control.vercel.app/
- https://seminario-final-five.vercel.app/
- https://mobile-importador-ofertas-de-carga.vercel.app/
- https://mobile-importador-panel-de-pago-seg.vercel.app/
- https://web-logistica-panel-de-mesa-de-lici.vercel.app/

La referencia prioritaria es el panel web de mesa de licitaciones. Las nuevas pantallas deben respetar su identidad y mejorar consistencia, legibilidad, accesibilidad y adaptación móvil sin reemplazarla por una plantilla genérica.

## Lenguaje visual

- Producto logístico premium, técnico y confiable.
- Fondos grafito muy oscuros, superficies elevadas y bordes discretos.
- Acentos cálidos ámbar/naranja para acciones, progreso y alertas operativas.
- Verde esmeralda para validaciones, estados seguros y operaciones completadas.
- Tipografía de alta legibilidad con números y datos operativos claramente jerarquizados.
- Tarjetas compactas, tablas legibles y estados visibles sin sobrecargar la interfaz.
- Microinteracciones sobrias; el movimiento debe explicar estados y no distraer.

## Tokens heredados de la referencia

- Fondo principal: `#07070A`.
- Superficie: `#0C0D12`.
- Superficie secundaria: `#111219`.
- Borde: `#1F2029`.
- Texto principal: `#FFFFFF`.
- Texto secundario: `#8A8B94`.
- Éxito y validación: `#10B981`.
- Acción y advertencia: gama ámbar/naranja.

## Criterios obligatorios

1. Web y APK deben sentirse como el mismo producto.
2. Cada flujo debe incluir carga, vacío, error, éxito y bloqueo por permisos.
3. Contraste y tamaño táctil deben ser suficientes para uso real.
4. La información crítica debe entenderse sin depender únicamente del color.
5. Cada hito funcional tendrá una revisión visual antes de darse por cerrado.
