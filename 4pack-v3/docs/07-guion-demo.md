# Guion de demostración — 4PACK

## Preparación

- Confirmar acceso a las tres cuentas demo sin mostrar contraseñas en pantalla.
- Usar una ventana normal para el importador y ventanas privadas separadas para operador y administrador.
- Tener preparado un PDF MSDS pequeño y válido.
- Verificar que Web, Supabase y APK estén disponibles.
- Partir de una carga nueva para que toda la historia sea visible.

## Relato de 10 a 12 minutos

### 1. Problema y propuesta — 1 minuto

4PACK conecta pequeños importadores con operadores logísticos en la ruta China–Argentina. Centraliza la publicación de cargas, la licitación inversa, la adjudicación y el seguimiento. La garantía es una simulación académica: la versión actual no custodia dinero real.

### 2. Importador publica — 2 minutos

1. Ingresar como importador.
2. Crear una carga desde Shenzhen con accesorios y baterías de litio.
3. Mostrar la detección preventiva HAZMAT.
4. Intentar continuar sin MSDS para evidenciar la validación.
5. Adjuntar el PDF y publicar.

### 3. Operador cotiza — 2 minutos

1. Ingresar como operador aprobado.
2. Abrir la oportunidad recién creada.
3. Presentar flete, costos, plazo, modalidad y condiciones.
4. Explicar que las ofertas están protegidas por rol y participación.

### 4. Importador compara y adjudica — 2 minutos

1. Volver al importador.
2. Comparar costo total, plazo, aduana y reputación.
3. Adjudicar la propuesta.
4. Mostrar la operación creada y confirmar la garantía simulada.

### 5. Operación y trazabilidad — 2 minutos

1. Como operador, registrar tránsito y ubicación.
2. Mostrar el historial y enviar un mensaje.
3. Adjuntar un documento privado.
4. Explicar que los hitos son cargados por usuarios autorizados y no provienen de telemetría externa.

### 6. Administración — 1 minuto

1. Ingresar como administrador.
2. Mostrar validación de operadores.
3. Abrir el panel con volumen garantizado y comisiones proyectadas.
4. Aclarar nuevamente que son valores simulados.

### 7. Android y cierre — 1 a 2 minutos

1. Abrir el APK y mostrar la misma cuenta y operación.
2. Recorrer oportunidades, operaciones y perfil.
3. Cerrar con la arquitectura compartida Web + Android + Supabase y la evolución futura hacia integraciones reales.

## Plan de contingencia

- Si falla Internet, usar capturas de una ejecución previa y explicar el mismo flujo.
- Si el APK no conecta, mostrar su navegación y completar el circuito en Web.
- Si una cuenta pierde la sesión, tener abiertas las otras dos ventanas sin revelar credenciales.
- No improvisar pagos, validaciones aduaneras ni tracking automático que no existan en el MVP.
